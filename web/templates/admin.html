数据迁移

把 ClearLove PHP 旧版（1.x）的帖子、评论、用户等数据迁移到当前站点

迁移说明

  • 支持旧版 SQLite 数据库文件（旧版根目录的 data.db）与 MySQL 导出的 .sql 文件（宝塔「数据库 → 备份」或 mysqldump），上传后自动识别
  • 迁移会保留原有 ID 与发布时间，旧版的「正常 / 隐藏」状态会自动换算为新版语义（不会出现帖子集体消失或隐藏帖冒出来）
  • 用户与管理员密码同为 bcrypt，迁移后可直接用原密码登录
  • 可重复执行：已存在的记录会自动跳过，不会产生重复数据
  • 迁移期间请勿发帖；数据量大时耗时较长，可以关闭页面稍后回来查看结果

上传旧版数据库

单个文件不超过 {{.maxMB}}MB。SQLite 请上传旧版根目录的 data.db；MySQL 请上传导出的 .sql。

填写服务器上的绝对路径时，会把旧站图片 / 视频复制到新版 uploads/legacy/；留空则只迁移文字数据（图片会缺失，但不影响帖子本身）。
